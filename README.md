# Página personal de Francisco Mulero López

Página personal estática desarrollada con HTML, CSS y JavaScript, con
pruebas automatizadas y despliegue en GitHub Pages mediante GitHub Actions.

URL publicada:
https://FranciscoMulero.github.io/pagina-personal/

- Node.js 22.
- npm.
- Git, si quieres trabajar con el repositorio.
